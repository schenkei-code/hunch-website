Loslegen

Hunch ist ein persönlicher intentional agent. Die Runtime wohnt auf deiner Maschine — Mac, PC oder VPS — liest aktivierte Signale mit, erkennt Absichten und handelt nur innerhalb deiner Regeln. Die iOS-App ist eine von mehreren Oberflächen auf denselben Kern.

Installation Heute

pipx install .          # oder: pip install .

hunch init              # Ordner anlegen, zeigen was fehlt
hunch check             # Antworten die Modelle? Was liegt hier?
hunch run               # läuft, auf 127.0.0.1:8000

hunch check endet mit Exit-Code 1, wenn etwas nicht antwortet — taugt für ein Startskript oder eine Überwachung.

Auf dem Server (systemd)

Vor dem Start stehen Bindung, Token und TLS-Pfade in ~/.hunch/env (0600). Die Runtime bindet ausschließlich an eine konkrete Adresse im eigenen Tailnet — nie an eine Wildcard-Adresse:

HUNCH_HOST=<tailscale-ip>
HUNCH_AUTH_TOKEN=…
HUNCH_TLS_CERT=~/.hunch/tls/hunch.crt
HUNCH_TLS_KEY=~/.hunch/tls/hunch.key

sudo cp deploy/hunch.service /etc/systemd/system/
sudo systemctl enable --now hunch
journalctl -u hunch -f

Die Unit läuft als eigener Nutzer. Wildcard- und LAN-Bindungen werden abgewiesen; eine Tailnet-Adresse ohne Token und TLS startet ebenfalls nicht.

Von unterwegs erreichen (privates Netz + TLS)

Hunch braucht keinen Dienst in der Mitte: Runtime und Telefon treffen sich in einem privaten Netz deiner Wahl (VPN oder Mesh-Netz zwischen deinen Geräten). iOS verlangt dabei HTTPS — also ein Zertifikat für den Hostnamen der Runtime im privaten Netz ausstellen (viele Mesh-VPNs bringen dafür ein eigenes Werkzeug mit), an die Adresse aus diesem Netz binden, Token setzen:

# Zertifikat für den privaten Hostnamen → ~/.hunch/tls/hunch.crt + hunch.key
HUNCH_HOST=<tailscale-ip> HUNCH_AUTH_TOKEN=… \
HUNCH_TLS_CERT=~/.hunch/tls/hunch.crt HUNCH_TLS_KEY=~/.hunch/tls/hunch.key hunch run

In der App den Namen eintragen, nicht die IP — das Zertifikat gilt für den Namen.

Direkt am Gedächtnis, ohne Server

hunch remember "Studio-Website bis Ende des Monats live"
hunch search Studio
hunch tasks

Diese Befehle arbeiten direkt in der lokalen Datenbank der Runtime. Die App führt eine getrennte lokale Datenbank; Brain-Sync gleicht Erinnerungen, Aufgaben, Vorhaben, Gespräche und Nachrichten beidseitig ab. Es gibt keine gemeinsam geöffnete Datenbankdatei.
