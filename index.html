Personal Agent Runtime

Agents that act on purpose, not on prompt.

Hunch fühlt sich nicht an wie ein Agent, sondern wie jemand, der dich kennt. Eine Runtime auf deiner Maschine, die mitliest, Absichten erkennt und handelt — mit einem Gedächtnis, das von überall erreichbar ist.

Early Access anfragen Wie es funktioniert

Läuft auf PC, Mac und VPS — deine Schlüssel, deine Maschine.

Zwei Modelle, getrennte Rollen

Einer liest mit. Eine handelt.

Ein großes Modell, das dauernd mitliest, kostet mehr als es einbringt. Deshalb trennt Hunch Wahrnehmung und Handlung.

Immer an · klein · notfalls lokal

Observer

Liest mit und antwortet nie. Er bündelt eingehende Ereignisse, hält sie gegen das Gedächtnis und schätzt, ob eine Absicht dahintersteckt. Erst wenn er sich sicher genug ist, weckt er die Executive.

Modell: frei wählbar — Ollama, LM Studio, jeder Endpunkt.

Wird geweckt · groß · abgesichert

Executive

Prüft, ob sie handeln darf, ruft Werkzeuge auf und meldet sich bei dir. Hier passiert etwas in der Welt — deshalb liegt davor der Governor und dahinter das Protokoll.

Davor: Risikoprüfung · dahinter: Fahrtenbuch.

Fähigkeiten

Vier Herkünfte, ein Verzeichnis.

Die Executive sieht keinen Unterschied, woher ein Werkzeug kommt.

EingebautAb Werk dabei

Gedächtnis durchsuchen, merken, Aufgaben, Kommandos, HTTP.

SkillsAnleitung oder Code

Eine SKILL.md als Anleitung fürs Modell oder eine Python-Datei, die ausgeführt wird.

MCPFremde Server

Werkzeuge fremder Server, dynamisch geladen — eine Config-Zeile genügt.

RESTOhne Code

Schnittstellen aus connectors.json — keine Zeile Code nötig.

ExternAgenten starten

Codex, Claude Code, Gemini CLI, Aider — die Runtime startet sie und holt das Ergebnis zurück.

ModelleNichts verdrahtet

Observer und Executive sitzen frei auf jedem Provider.

Läuft auf macOS Läuft auf Windows Läuft auf Linux / VPS iOS-App funktioniert auch allein
Ein Gedächtnis, überall

Nicht eine Kopie. Dieselbe Datenbank.

Runtime und iOS-App teilen sich ein Brain — und jeder MCP-fähige Agent auf derselben Maschine liest und ergänzt dasselbe Gedächtnis.

Abgleich mit der App

Ein Aufruf, beide Richtungen

Die App schickt ihre Änderungen und sagt, was sie zuletzt gesehen hat — zurück kommt alles Übrige. Erinnerungen wachsen nur, Dubletten werden verworfen; ein doppelter Abgleich richtet keinen Schaden an. Bei Aufgaben gewinnt der jüngere Stand.

Schnittstelle: POST /brain/sync mit Cursor aus Zeitstempel und ID.

Für andere Agenten

Claude Code sieht dasselbe

Ein Befehl, und jeder MCP-fähige Agent hat Zugriff: Suchen, Merken, Aufgaben. Bewusst kein run_command und kein run_agent — ein fremder Agent hängt nicht am Governor dieser Runtime und bekommt deshalb nur das Gedächtnis.

Anbinden: claude mcp add hunch — python -m hunch_runtime.mcp_server

Schutzschilde

Handeln ja. Durchdrehen nein.

Sieben Bremsen liegen zwischen einer Absicht und der Welt — dieselben Risikostufen wie in der iOS-App, damit es nur eine Wahrheit gibt.

KostenTagesbudget in Token

Ist es erschöpft, hört auch der Observer auf mitzulesen.

RisikoDrei Stufen

read_only, write_low_risk, critical_action — identisch zur App.

FreigabeKritisches fragt nach

Immer, und mit Vorschau des Aufrufs — nie blind bestätigen.

ImpulseKeine Spam-Maschine

Mindestabstand plus Tagesgrenze; Unterdrücktes wird abgelegt statt verworfen.

WerkzeugeFehler-Pause

Drei Fehlschläge in Folge, dann fünf Minuten Pause für das Werkzeug.

ProtokollNur Anhängen

Jede Entscheidung steht mit Begründung im Fahrtenbuch.

Eingänge

Ein Agent, der nur auf Anstupsen reagiert, ist ein Chatbot.

Ereignisse kommen von überall — und alles Fremde wird dem Modell als Zitat vorgelegt, nie als Auftrag.

TaktHeartbeat

Alle 30 Minuten ein Blick aufs Gedächtnis — nachts still, wenn du das willst.

TelegramEin fester Chat

Impulse gehen in denselben Chat zurück. Fremde Chats werden weggefiltert — ein offenes Mikrofon gibt es nicht.

OrdnerDateien im Blick

Neue und geänderte Dateien in einem beobachteten Ordner werden gemeldet.

Zur Dokumentation

Prinzipien

Gebaut wie ein Werkzeug, nicht wie eine Demo.

01

Gedächtnis mit Löschtaste

Hunch erinnert sich — durchsuchbar, von überall. Und was gelöscht ist, ist gelöscht. Ein Gedächtnis ohne Löschtaste wäre eine Überwachung.

02

Begründung vor Handlung

Jede Handlung hat eine Absicht, ein Fahrtenbuch und einen Rückweg. Kein stilles Durchregieren.

03

Deine Maschine, deine Schlüssel

Die Runtime wohnt bei dir — PC, Mac oder VPS. API-Schlüssel bleiben lokal, lokale Modelle sind erste Klasse.

04

Vertrauen pro Gerät

Eigene Geräte kommen ohne Passwort rein, fremde einmalig mit Code. Drei Stufen, sauber getrennt.
